# Excalidraw

> Home for hand-drawn diagrams (architecture, flows, mind maps). Create Excalidraw drawings here and link them from your notes.

## How to Use
1. Install the **Excalidraw** community plugin (Settings → Community plugins).
2. Set this folder as the Excalidraw default folder (plugin settings → "Excalidraw folder" = `18 Excalidraw`).
3. Create a drawing: command palette → *Excalidraw: Create new drawing*.
4. Embed a drawing in any note with `![[Drawing Name.excalidraw]]`, or link it with `[[Drawing Name.excalidraw]]`.

## Suggested Naming
Match the topic so drawings are easy to find and link:
- `Java - JVM Architecture.excalidraw`
- `Spring - Request Lifecycle.excalidraw`
- `System Design - URL Shortener.excalidraw`
- `Kafka - Partitions and Consumer Groups.excalidraw`

## Suggested Organization
As drawings grow, group them into subfolders per domain (mirroring the vault):
```
18 Excalidraw/
  01 Java/
  02 Spring/
  03 Microservices/
  04 System Design/
  ...
```

## Diagram Ideas by Domain
- [[Java]] — JVM architecture, memory areas, GC, HashMap internals.
- [[Spring]] — bean lifecycle, DispatcherServlet request flow, security filter chain.
- [[Microservices]] — service topology, Saga flows, circuit breaker states.
- [[Apache Kafka|Kafka]] — topic/partition/offset model, consumer groups.
- [[Kubernetes]] — cluster architecture, pod networking.
- [[System Design]] — case-study architectures (start from the [[Case Studies Index|case studies]]).

## Notes
- Excalidraw files are stored as Markdown-compatible `.excalidraw.md` (or `.excalidraw`) so they live happily in the vault and appear in Graph View.
- Keep one drawing per concept; link it from the concept's note under a "## Diagram" heading.
