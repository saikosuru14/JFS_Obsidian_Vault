# Projects

> Domain hub — hands-on builds that tie the whole stack together.

## Overview
Projects turn theory into portfolio-ready experience. This domain groups project ideas, full application builds, and DevOps/deployment projects.

## Learning Roadmap
1. [[Getting Started Index|Getting Started]] — project ideas and how to choose one.
2. [[Application Projects Index|Application Projects]] — end-to-end apps (banking, e-commerce, chat, and more).
3. [[DevOps Projects Index|DevOps Projects]] — CI/CD, Kubernetes, and AWS deployment.

## Suggested Study Order
Pick an application project that exercises [[Spring]] + a database, ship it, then wrap it with the DevOps projects (containerize, build a pipeline, deploy to the cloud).

## Prerequisites
- [[Java]], [[Spring]], and [[Database Fundamentals]].
- For DevOps projects: [[Docker]], [[Kubernetes]], [[CI-CD]], [[AWS]].

## Related Concepts
- [[Microservices]] — several projects use a microservice architecture.
- [[System Design]] — apply design decisions in real builds.

## Suggested Build Order
1. A CRUD app ([[Employee Management Portal]] or [[Order Management System]]).
2. A microservices app ([[E-Commerce Microservices]] or [[Food Delivery Platform]]).
3. Containerize and ship it ([[CI-CD Pipeline Project]] → [[Kubernetes Deployment Project]] → [[AWS Deployment Guide]]).
