# Bases - README

This folder holds the **central** bases and tracker notes. Each learning domain also has its **own** base inside its folder.

## Contents
- `Master.base` — all notes across the vault, grouped by domain.
- `Database.base` — focused database-fundamentals tracker.
- [[Bases|00 Bases Index]] — overview of the whole base system.
- [[Properties Guide]] — the frontmatter schema and allowed values.
- Tracker notes that embed live base views: [[Master Learning Tracker]], [[Java Tracker]], [[Interview Tracker]], [[Revision Tracker]].

## Where the Per-Domain Bases Live
Each domain folder contains a `<Domain>.base` grouped by module and sorted by `order`:
`03 Java/Java.base`, `04 Spring/Spring.base`, `05 Microservices/Microservices.base`, and so on.

## Adding a New Topic
1. Create the note inside the right `NN Module` folder using a [[Templates|template]].
2. Fill the frontmatter per the [[Properties Guide]].
3. Done — the domain base and Master base pick it up automatically.

See [[Bases|the Bases Index]] for the full map.
