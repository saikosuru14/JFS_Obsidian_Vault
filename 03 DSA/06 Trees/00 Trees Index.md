# Trees

> Module index - part of the [[DSA Index|DSA]] learning path.

## Overview
A tree is a hierarchical structure of nodes with one root and no cycles. Trees give O(log n) operations when balanced and model hierarchies, ordered data, priority scheduling, and prefix lookups. Most tree problems reduce to a traversal plus recursion.

## Branches (expand each)
- **[[Binary Tree]]** — up to two children per node.
  - [[Tree Traversals]] — inorder/preorder/postorder/level-order.
  - [[Binary Search Tree]] — ordered binary tree, O(log n) search.
    - [[Balanced Trees]] — AVL / red-black self-balancing.
- **[[Heap]]** — complete tree for priority (min/max).
- **[[Trie]]** — prefix tree for strings.
