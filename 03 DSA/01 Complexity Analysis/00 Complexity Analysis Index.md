# Complexity Analysis

> Module index - part of the [[DSA Index|DSA]] learning path.

## Overview
Complexity analysis is how you reason about an algorithm's cost as input grows, independent of hardware. It's the language you use in every interview to compare solutions and justify a data-structure choice.

## Branch (expand)
- **[[Big O Notation]]** — asymptotic upper bound; the vocabulary.
  - [[Time Complexity]] — how running time scales.
  - [[Space Complexity]] — how extra memory scales.
  - [[Amortized Analysis]] — average cost over a sequence of operations.

## Quick Revision
- Big O = worst-case growth rate. Analyze time and space. Amortized = average per op across a sequence (e.g., ArrayList add is amortized O(1)).
