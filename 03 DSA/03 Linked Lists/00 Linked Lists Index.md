# Linked Lists

> Module index - part of the [[DSA Index|DSA]] learning path.

## Overview
A linked list stores elements in nodes connected by pointers, giving O(1) insert/delete at a known position but O(n) access. Interviews love them because pointer manipulation (reversal, cycle detection, merging) tests careful reasoning.

## Branches (expand each)
- **[[Singly Linked List]]** — one-directional nodes.
  - [[Doubly Linked List]] — bidirectional nodes.
- **[[Fast and Slow Pointers]]** — the tortoise/hare technique.
- **[[Reversal and Cycle Detection]]** — the two must-know operations.
