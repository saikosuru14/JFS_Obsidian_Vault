# Dynamic Programming

> Module index - part of the [[DSA Index|DSA]] learning path.

## Overview
Dynamic programming solves problems with **overlapping subproblems** and **optimal substructure** by solving each subproblem once and caching it. It's the highest-difficulty interview area — the skill is recognizing the state and writing the recurrence.

## Quick Revision
- Overlapping subproblems + optimal substructure -> cache subresults. Top-down (memo) or bottom-up (tabulation). Define state, recurrence, base case, order. Patterns: knapsack, LCS, LIS, grid, intervals.
