# Stacks and Queues

> Module index - part of the [[DSA Index|DSA]] learning path.

## Overview
Stacks (LIFO) and queues (FIFO) are restricted-access linear structures. They model recursion, undo, BFS ordering, scheduling, and — via the **monotonic stack** — a powerful pattern for "next greater/smaller element" problems.

## Branches (expand each)

  - [[Monotonic Stack]] — next greater/smaller element pattern.
- **[[Queue]]** — FIFO.
  - [[Deque]] — double-ended queue.
