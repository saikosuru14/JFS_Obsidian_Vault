# Arrays and Strings

> Module index - part of the [[DSA Index|DSA]] learning path.

## Overview
Arrays and strings are the most common interview substrate. Beyond the structures themselves, the value is in the **patterns** that solve array/string problems in linear time: two pointers, sliding window, and prefix sums.

## Branches (expand each)
- **[[Arrays]]** — contiguous, indexed storage.
  - [[Prefix Sum]] — O(1) range queries.
- **[[Strings]]** — immutable char sequences + StringBuilder.
- **[[Two Pointers]]** — converging/parallel indices.
  - [[Sliding Window]] — dynamic subarray/substring ranges.

## Learning Roadmap
1. [[Arrays]] -> [[Prefix Sum]]
2. [[Strings]]
3. [[Two Pointers]] -> [[Sliding Window]]

## Quick Revision
- Arrays: O(1) index, O(n) insert/search. Patterns: two pointers (sorted/pairs), sliding window (contiguous subarray), prefix sum (range queries). Strings are immutable — use StringBuilder.
