# Recommended Books

> Grouped by domain. Start with the bold titles.

## Core Java — [[Java]]
- **Effective Java** — Joshua Bloch (idioms and best practices).
- Java Concurrency in Practice — Brian Goetz (the concurrency reference).
- Head First Java — gentle introduction.
- Modern Java in Action — streams, lambdas, functional style.

## Spring — [[Spring]]
- **Spring in Action** — Craig Walls.
- Pro Spring / Spring Boot in Practice.

## Databases — [[Database Fundamentals]]
- **Designing Data-Intensive Applications** — Martin Kleppmann (also core for system design).
- SQL Performance Explained — Markus Winand.

## System Design — [[System Design]]
- **System Design Interview, Vol 1 & 2** — Alex Xu.
- Designing Data-Intensive Applications — Kleppmann.

## Microservices & Distributed — [[Microservices]]
- Building Microservices — Sam Newman.
- Microservices Patterns — Chris Richardson.

## DevOps & Cloud — [[Docker]] / [[Kubernetes]] / [[AWS]]
- The DevOps Handbook.
- Kubernetes Up & Running.
- AWS Certified Solutions Architect Study Guide.

## Fundamentals — [[Computer Science]]
- Clean Code & Clean Architecture — Robert C. Martin.
- Head First Design Patterns.

## Interview — [[Interview]]
- Cracking the Coding Interview — Gayle Laakmann McDowell.
- Grokking the System Design Interview (course/book).
