# Streams API

> Module index - part of the [[Java Index|Java]] learning path.

## Overview
The Streams API (Java 8) processes sequences of elements through a **declarative pipeline**: a source, lazy intermediate operations, and one terminal operation. Built on [[Functional Programming Index|functional interfaces]], it replaces most manual loops with readable transformations.
