# JVM Performance

> Module index - part of the [[Java Index|Java]] learning path.

## Overview
Getting peak performance from the JVM: how the **JIT** compiles hot code and applies **escape analysis**, how to **tune GC** for throughput vs latency, and how to **profile** to find the real bottleneck. The theme throughout: measure before you optimize.

## Branches (expand each)
- **[[JIT Compilation]]** — tiered compilation, inlining, deoptimization.
- **[[Escape Analysis]]** — scalar replacement, stack allocation, lock elision.
- **[[GC Tuning]]** — collector choice, heap sizing, pause targets.
- **[[Performance Profiling]]** — JFR, async-profiler, JMH, heap dumps.
