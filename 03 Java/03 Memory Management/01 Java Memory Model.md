# Java Memory Model (JMM)

## Purpose
The Java Memory Model defines how threads interact through memory and guarantees visibility, ordering and atomicity.

## Key Concepts
- Main Memory
- Working Memory
- Happens-Before
- volatile
- synchronized

## Why it matters
Incorrect understanding leads to race conditions and stale reads.
