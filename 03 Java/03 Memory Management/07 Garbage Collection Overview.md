# Garbage Collection

GC automatically reclaims memory occupied by unreachable objects.

## Benefits
- Prevents most memory leaks
- Eliminates manual deallocation
- Improves reliability

## Major Collectors
- Serial GC
- Parallel GC
- G1 GC
- ZGC
- Shenandoah
