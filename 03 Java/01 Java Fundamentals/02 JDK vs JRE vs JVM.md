# JDK vs JRE vs JVM

## JVM
Executes bytecode.

## JRE
Provides libraries and runtime required to execute Java applications.

## JDK
Contains the compiler (javac), runtime and development tools.

Flow:
.java -> javac -> .class -> JVM -> Machine Code
