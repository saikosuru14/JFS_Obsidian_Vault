# Reflection & Annotations

> Module index - part of the [[Java Index|Java]] learning path.

## Overview
**Reflection** inspects and manipulates classes, methods, and fields at runtime; **annotations** attach metadata that reflection (or the compiler) reads. Together they power the "magic" in Spring, Hibernate, Jackson, and JUnit — dependency injection, ORM mapping, serialization, and test discovery.

## Branch (expand)
- **[[Reflection]]** — runtime introspection and dynamic invocation.
- **[[Annotations]]** — metadata, retention policies, custom annotations.
