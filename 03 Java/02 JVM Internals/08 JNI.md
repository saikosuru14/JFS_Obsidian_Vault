# Java Native Interface (JNI)

JNI allows Java code to interact with native libraries.

Use Cases:
- Hardware access
- Legacy C/C++ libraries
- OS-specific features

Trade-offs:
- Reduced portability
- Harder debugging
- Potential memory safety issues
