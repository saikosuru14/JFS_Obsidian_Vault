# Final Learning Roadmap

> The end-to-end order for going from fundamentals to job-ready across the whole vault.

## Phase 1 — Foundations
1. [[Computer Science]] — [[Object-Oriented Programming]], [[SOLID Principles]], [[Design Patterns Overview|Design Patterns]].
2. [[Database Fundamentals]] — ACID, transactions, indexing, normalization.
3. [[Computer Networks]] — HTTP, TCP/UDP, DNS.

## Phase 2 — Core Java
4. [[Java]] — fundamentals → JVM → memory → collections → concurrency.

## Phase 3 — Frameworks
5. [[Spring]] — core → boot → MVC → data JPA → security.

## Phase 4 — Distributed Systems
6. [[Microservices]] — communication, discovery, resilience, eventing.
7. [[Apache Kafka|Kafka]] — streaming and messaging backbone.

## Phase 5 — Cloud & DevOps
8. [[Docker]] → [[Kubernetes]] → [[CI-CD]] → [[AWS]].

## Phase 6 — Design & Interview
9. [[System Design]] — fundamentals, building blocks, case studies.
10. [[Interview]] — Q&A, HLD/LLD, behavioral.

## Phase 7 — Apply It
11. [[Projects]] — build, containerize, and deploy an end-to-end app.

## Milestones
- [ ] Explain the four OOP pillars and SOLID with examples.
- [ ] Build a Spring Boot REST API with JPA and security.
- [ ] Design and reason about a microservices system with Kafka.
- [ ] Containerize and deploy to Kubernetes via a CI/CD pipeline.
- [ ] Complete two system-design case studies end to end.
