## How the Vault Works
- **One concept = one note**, grouped into `NN Module` folders under each domain.
- Numbered filenames set reading order; `aliases` keep wiki links clean.
- Open any domain's `.base` file to see all its notes grouped by module and sorted by learning order.
- Track progress with the `status`, `priority`, `interview`, and `revision` properties.
