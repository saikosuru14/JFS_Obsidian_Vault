# Operating Systems

> Module index — core OS concepts every backend engineer should know.

## Overview
An operating system manages hardware resources (CPU, memory, devices) and provides services and abstractions to applications through system calls.

## Learning Path
1. [[Processes vs Threads]]
2. [[CPU Scheduling]]
3. [[Context Switching]]

5. [[Memory Management]]
6. [[Virtual Memory]]
7. [[Locks]]

## Responsibilities
- Process & thread management
- Memory management and virtual memory
- File systems and device management
- Security and isolation (user vs kernel mode)

## Why Java Developers Should Care
OS concepts explain CPU spikes, memory pressure and GC pauses, thread contention, context-switch overhead, and I/O bottlenecks.

## Interview Questions
- What is a system call? User mode vs kernel mode?
- Process vs thread — how do they differ?
- What causes a deadlock and how do you prevent it?

## Revision Summary
- OS manages CPU, memory, devices and provides isolation.
- Master processes/threads, scheduling, memory, and deadlocks.
