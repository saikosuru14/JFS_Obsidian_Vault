# Computer Science

> Domain hub — the CS fundamentals that underpin Java, Spring, and system design.

## Modules (Learning Order)
1. **[[Object-Oriented Programming]]** — classes, the four pillars, object relationships.
2. **[[SOLID Principles]]** — five design principles for maintainable code.
3. **[[Design Patterns Overview]]** — reusable creational, structural, behavioral solutions.
4. **[[Operating Systems]]** — processes, threads, scheduling, memory.
5. **[[Computer Networks]]** — OSI, TCP/UDP, HTTP, DNS, load balancing.
6. **[[Database Fundamentals]]** — ACID, transactions, isolation, indexing.

## How This Connects
- OOP + SOLID + patterns → clean, extensible **[[Java]]** and **[[Spring Framework|Spring]]** code.
- OS + networks + databases → the foundation for **[[System Design]]** and **[[Microservices]]**.

## Suggested Study Flow
Start with OOP and SOLID (they recur everywhere), then databases and networks (interview-heavy), then operating systems and design patterns.

## Revision Summary
- Six modules: OOP, SOLID, Design Patterns, OS, Networks, Databases.
- These fundamentals feed directly into Java, Spring, and system design.
