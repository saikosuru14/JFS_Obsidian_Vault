# Object-Oriented Programming

> Module index — the learning path and hub for OOP fundamentals.

## Overview
Object-Oriented Programming (OOP) models software as interacting **objects** that bundle state (fields) and behavior (methods). It improves modularity, reusability, extensibility, and testability as systems grow.

## The Four Pillars
- **[[Encapsulation]]** – bundle data + behavior, hide internal state.
- **[[Abstraction]]** – expose a contract, hide implementation.
- **[[Inheritance]]** – reuse behavior through an is-a relationship.
- **[[Polymorphism]]** – one interface, many implementations at runtime.

## Design Relationships
- **[[Composition vs Inheritance]]** – favor composition (has-a) over inheritance (is-a).
- **[[Association Aggregation Composition]]** – how objects relate and own one another.

## Where It Leads
- **[[SOLID Principles]]** – design principles built on OOP.
- **[[Design Patterns Overview]]** – reusable solutions expressed with OOP.
- Spring uses interfaces + composition heavily via dependency injection.
