# TCP vs UDP

## TCP
- Reliable
- Ordered
- Connection-oriented
- Retransmissions
- Flow control

Used by:
- HTTP/HTTPS
- JDBC
- Kafka

## UDP
- Fast
- No delivery guarantee
- Connectionless

Used by:
- DNS
- Streaming
- VoIP
