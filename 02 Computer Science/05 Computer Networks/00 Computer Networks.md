# Computer Networks

> Module index — the networking foundations behind every API, DB call, and message.

## Overview
Every Spring Boot REST call, database query, Kafka message, and microservice request travels over a network. Understanding the layers helps you reason about latency, failures, and security.

## Learning Path
1. [[OSI Model]]
2. [[TCP vs UDP]]
3. [[HTTP and HTTPS]]
4. [[DNS]]
5. [[REST APIs]]
6. [[Load Balancers]]
7. [[Reverse Proxy]]

## Key Themes
- Layered models (OSI / TCP-IP) and where protocols sit.
- Reliable vs unreliable transport (TCP vs UDP).
- Application protocols (HTTP/HTTPS) and name resolution (DNS).
- Traffic distribution and indirection (load balancers, reverse proxies).

## Interview Questions
- Walk through what happens when you type a URL and press enter.
- TCP vs UDP — when would you choose each?
- Difference between a load balancer and a reverse proxy?

## Revision Summary
- Learn the layers, then transport, then application protocols and edge components.
