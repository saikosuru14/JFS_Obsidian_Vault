# HTTP & HTTPS

HTTP is a stateless application-layer protocol.

Methods:
- GET
- POST
- PUT
- PATCH
- DELETE

HTTPS = HTTP + TLS encryption.

Status Codes
- 2xx Success
- 3xx Redirect
- 4xx Client Error
- 5xx Server Error

### Spring Connection
Spring MVC and Spring Boot build REST APIs over HTTP.
