# CI/CD

> Domain hub — automating build, quality, and deployment.

## Overview
Continuous Integration and Continuous Delivery automate the path from source code to running software: build tools compile and package, pipelines run tests and quality gates, artifacts are stored, and deployments ship to containers and clusters.

## Learning Roadmap
1. [[Git Index|Git]] — version control, branching, merge/rebase, PRs, branching strategies.
2. [[Build Tools Index|Build Tools]] — Maven and Gradle.
3. [[CI Pipelines Index|CI Pipelines]] — build pipelines, GitHub Actions, Jenkins.
4. [[Code Quality and Artifacts Index|Code Quality & Artifacts]] — SonarQube, Nexus, artifact repositories.
5. [[CD and Deployment Index|CD & Deployment]] — Docker and Kubernetes pipelines, GitOps.

## Suggested Study Order
Start with Git (version control is the foundation of CI/CD), then build tools, then how CI pipelines orchestrate builds and tests, then quality gates and artifact management, and finally continuous deployment to containers and clusters.

## Prerequisites
- [[Docker]] and [[Kubernetes]] basics.

## Related Concepts
- [[AWS]] — managed pipelines and deployment targets.
- [[Microservices]] — independent service delivery.

## Interview Focus
- CI vs CD vs continuous deployment.
- Pipeline stages and quality gates.
- Artifact versioning and promotion.
- GitOps and declarative deployments.
