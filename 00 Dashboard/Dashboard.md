## Daily Workflow
1. Pick one topic (from a domain index or [[Learning Dashboard]]).
2. Study and update the note.
3. Draw a diagram in [[Excalidraw]] if helpful.
4. Link related notes.
5. Mark shaky topics `Need Revision`; review via the [[Revision Dashboard]].
