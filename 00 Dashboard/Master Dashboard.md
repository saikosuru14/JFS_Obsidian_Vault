## How to Use
1. Set each note's `status` as you go: `Not Started → Learning → Completed`.
2. Mark shaky topics `Need Revision`; they surface in the Revision Dashboard.
3. Use `priority` and `interview` to focus limited study time.
4. Review weekly; update statuses; repeat.
