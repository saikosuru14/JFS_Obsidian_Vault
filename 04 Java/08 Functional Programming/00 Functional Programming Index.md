# Functional Programming

> Module index - part of the [[Java Index|Java]] learning path.

## Overview
Java 8 added a functional style built on **functional interfaces** (single-abstract-method types) that lambdas and method references implement. This is the foundation for the [[Streams API Index|Streams API]] and modern callback-based code.

## Branch (expand)
- **[[Functional Interfaces]]** — the target types (`Function`, `Predicate`, `Consumer`, `Supplier`).
  - [[Lambda Expressions]] — concise inline implementations.
    - [[Method References]] — shorthand for lambdas that call one method.
