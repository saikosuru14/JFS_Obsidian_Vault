# Java Full Stack Roadmap

> **Goal:** Java Full Stack / Backend Engineer (4–5 YOE level).

## The Path
```
Computer Science
  ↓
Core Java  →  JVM  →  Collections  →  Concurrency
  ↓
Spring (Core → Boot → MVC → Data JPA → Security)
  ↓
SQL / Databases
  ↓
Microservices  →  Kafka
  ↓
Docker  →  Kubernetes  →  CI/CD  →  AWS
  ↓
System Design
  ↓
Projects
  ↓
Interview Preparation
```

## Linked Milestones
1. [[Computer Science]] — OOP, SOLID, DB, networks.
2. [[Java]] — language, JVM, collections, concurrency.
3. [[Spring]] — core, boot, MVC, data, security.
4. [[Microservices]] + [[Apache Kafka|Kafka]] — distributed systems.
5. [[Docker]] → [[Kubernetes]] → [[CI-CD]] → [[AWS]] — cloud & DevOps.
6. [[System Design]] — scale and trade-offs.
7. [[Projects]] — build and ship.
8. [[Interview]] — Q&A, HLD/LLD, behavioral.
