# AWS

> Domain hub — the core AWS services for building and running backends.

## Overview
Amazon Web Services provides the compute, storage, networking, messaging, security, and operational building blocks for cloud applications. This domain organizes the most interview-relevant services by category.

## Learning Roadmap
1. [[Compute Index|Compute]] — EC2, Lambda, ECS, EKS, Auto Scaling.
2. [[Storage and Databases Index|Storage & Databases]] — S3, RDS, DynamoDB, ElastiCache.
3. [[Networking Index|Networking]] — VPC, Route 53, ELB, API Gateway, Security Groups.
4. [[Messaging and Events Index|Messaging & Events]] — SQS, SNS, EventBridge.
5. [[Security and Identity Index|Security & Identity]] — IAM, Secrets Manager.
6. [[Management and Monitoring Index|Management & Monitoring]] — CloudWatch, CloudFormation, Systems Manager, CLI.

## Suggested Study Order
Start with compute and storage (the foundation), then networking (VPC is central), then messaging, security/identity (IAM everywhere), and finally management and observability.

## Prerequisites
- [[Computer Networks]] and [[Docker]] / [[Kubernetes]] basics.

## Related Concepts
- [[CI-CD]] — deploying to AWS.
- [[System Design]] — applying these services at scale.

## Interview Focus
- EC2 vs Lambda vs ECS/EKS trade-offs.
- S3 vs RDS vs DynamoDB selection.
- VPC, subnets, and security groups.
- SQS vs SNS vs EventBridge.
- IAM roles and least privilege.
